후면 제거  
0519-2. cpp
```c++
bool bCull = false; // or true
```
```c++
void RenderScene(void) {

	if (bCull)                 // true 면
		glEnable(GL_CULL_FACE);  // 후면제거 기능 ON (후면 제거)
	else                       // false 면
		glDisable(GL_CULL_FACE); // 후면제거 기능 OFF (후면 존재)
```

OpenGL이 물체의 앞면만 그리도록 하거나 뒷면만 그리도록 하면 이미지 렌더링에 필요한 처리 시간을 줄일 수 있다.  

- 깊이 테스팅을 적용한 경우와 결과는 같다고 해도, 그렸지만 보이지 않는 것과 아예 그리지 않는 것의 성능 차이는 있다.
  
★ 정점들이 3차원공간에서 2차원 화면공간으로 투영 후 해당 정점들이 정의된 순서로 연결될 때 화면상에서 그려지는 방향이 중요하다
- 카메라가 보는 방향 기준
glEnable(GL_CULL_FACE); // 후면 제거 기능 활성(기본값=비활성)
결과가 제대로 나오냐? 왜?
- 점이 생성되는 순서를 확인

중요한 점 :  
“어떤 면이 후면(back face)인가?” 를 OpenGL이 어떻게 판단하냐  
그걸 정점 순서(CCW/CW)로 판단함    

현재 코드 :  
x = 50 * cos(angle);  
y = 50 * sin(angle);  
점이 반시계방향(CCW)으로 생성됨  

따라서 OpenGL은 "이건 앞면(front)" 이라고 인식
따라서 glEnable(GL_CULL_FACE); 하면, 화면에 보이는 앞면은 그리고, 뒷면은 안그림  

만약 점이 시계방향(CW)으로 생성된다면 :
x = 50 * sin(angle);
y = 50 * cos(angle);

OpenGL은 "이건 뒷면(back)" 이라고 인식  
glEnable(GL_CULL_FACE); 하면, 화면에 안보이는 앞면은 그리고, 화면에 보이는 뒷면은 안그림  
화면에 지금 보이는 게 뒷면 이니까!!
